Search files by regex pattern. Use this tool — not bash grep or rg — to search for code, text, or patterns across files.

Parameters:
- **pattern**: Regular expression to search for in file contents.
- **path** (optional): Directory or file to search. Defaults to the working directory.
- **include** (optional): Glob pattern to filter which files are searched (e.g. `*.go`, `*.{ts,tsx}`).
